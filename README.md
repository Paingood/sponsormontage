# Спонсорские вставки

## MusorDrop — `musordrop_insert.py`

Берёт готовый смонтированный ролик и делает версию с баннером MusorDrop посередине.

```
python musordrop_insert.py путь\к\ролику.mp4
```

На выходе рядом с исходником:
- `<имя>_musordrop.mp4` — готовый ролик;
- `<имя>_musordrop_check.png` — кадр из середины ролика (туда смотрит проверяющий, там должен быть баннер).

Опции:
- `-o файл.mp4` — куда сохранить;
- `--banner файл.mp4` — другой баннер (по умолчанию `assets/musordrop_banner.mp4`, это «musordrop animation green-screen sound on.mp4» из канала Musor TikTok);
- `--preview` — быстрый черновик, короткая сторона 540 px.

Нужен ffmpeg в PATH (Windows: `winget install ffmpeg`) и Python 3.8+. Других зависимостей нет.

### Что делает скрипт по правилам MusorDrop (на 02.10.2026)

| Правило | Как сделано |
|---|---|
| Ролик до 2 мин — один баннер в середине (с учётом рекламы), допуск 2–3 с | Середина итогового ролика попадает в баннер; скрипт проверяет это и пишет `OK` |
| Звук баннера обязателен | Звук баннера остаётся, громкость подгоняется под громкость ролика |
| Ускорение до 1.2x | 1.2x: 6 с → 5 с |
| Баннер не меньше 25% экрана | Видимая панель занимает 28%. На всю ширину выходит только 24,7%, поэтому края баннера чуть обрезаются |
| Если в ролике говорят — пауза | Рез в самой тихой точке рядом с серединой, ролик и звук стоят, фон — размытый стоп-кадр |

Ролик длиннее 2:00 — скрипт предупредит: там нужны два баннера (0:30 и 1:30), а он пока ставит только один.

Подача видео теперь только через сайт: musordrop.app/account/videos.
