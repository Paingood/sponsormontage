# Спонсорские вставки (sponsormontage)

Один скрипт `sponsor_cut.py`: берёт готовый смонтированный ролик и делает версию со спонсорским баннером по правилам из `rules.json`. Сейчас есть MusorDrop (по умолчанию) и FloatUP.

```
python sponsor_cut.py ролик.mp4                     # MusorDrop
python sponsor_cut.py ролик.mp4 --sponsor floatup
python sponsor_cut.py ролик.mp4 --sponsor all       # все спонсоры по очереди
python sponsor_cut.py C:\Users\Schoko\Desktop\aivideos\niko   # папка проекта
```

Рядом с роликом появятся:
- `<ролик>_musordrop.mp4` — готовая версия;
- `<ролик>_musordrop_check.png` — кадр, куда смотрит проверяющий (там должен быть баннер);
- `<ролик>_sponsors_report.txt` — проверки по правилам.

Опции:
- `--hd` — выход 1080×1920 вместо 4K. TikTok всё равно показывает 1080p, а собирается в разы быстрее;
- `--preview` — быстрый черновик, короткая сторона 540;
- `--cpu` — не использовать видеокарту;
- `--banner-volume 0.75` — громкость баннера относительно ролика;
- `--out-dir папка` — куда сохранять.

Нужен ffmpeg в PATH (Windows: `winget install ffmpeg`) и Python 3.8+, других зависимостей нет.

## Как работает

- **Тайминг.** MusorDrop: ролик до 2 мин — один баннер, середина итогового ролика попадает в баннер; длиннее — 0:30, 1:30… FloatUP: 0:20, 1:20…; ролик короче минуты — середина.
- **Рез.** В самой тихой точке у нужной секунды. Если рядом с роликом лежит `timeline.json` со словами — в паузе между словами.
- **Пауза.** Основное видео и звук стоят, фон — размытый затемнённый стоп-кадр последнего кадра перед резом.
- **Баннер.** По центру, зелёный фон вырезается, максимальное разрешённое ускорение (MusorDrop 1.2x → 5 с, FloatUP 1.5x → 3,5 с), звук на 25% тише ролика.
- **Размер.** MusorDrop — 28% экрана (нужно от 25%; на всю ширину выходит 24,7%, поэтому края баннера чуть обрезаны). FloatUP — на всю ширину без обрезки, 31,6% (нужно от 30%).
- **Скорость.** Кодирует на видеокарте (NVIDIA / Intel / AMD), если есть, иначе libx264 veryfast.

Правила и ставки спонсоров — в `sponsors.md`, экспорты их Telegram-каналов — в `sposors/`.
